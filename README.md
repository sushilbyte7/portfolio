# Sushil Kumar — Portfolio

Personal portfolio website of **Sushil Kumar** (MCA graduate, Pimpri Chinchwad University, Pune), live at [www.devsushil.in](https://www.devsushil.in).

It showcases my projects, skills and education:

- **ServeEase** — full-stack on-demand home services booking platform (React, Node.js, Express, MongoDB) with a Python/Flask sentiment-analysis microservice for customer reviews.
- **Apex Bike Rental System** — bike rental management system (PHP, MySQL, Bootstrap).
- **Reels Subtitle Generator** and **College WiFi Auto-Login** — utility tools.

## Tech Stack

React (Create React App), styled-components, Material UI, Framer Motion, EmailJS (contact form).

## Run locally

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

Deployed on Vercel from the `master` branch.
